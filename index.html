ORGANIZATIONAL ENTREPRENEURIAL READINESS ASSESSMENT

Assess readiness.

OERA is a generic model for assessing whether an organization has the conditions required to identify opportunities, experiment under uncertainty, learn from evidence, and scale successful change. This instance applies the model to a real partner organization, using five capabilities drawn from direct evidence rather than the full generic set.

CORE QUESTION

How ready is the organization to identify opportunities, experiment, learn, and turn successful ideas into sustainable organizational change?

01 · MODEL LOGIC

Direction → Enable → Discover → Act → Learn & Scale

The model treats entrepreneurial readiness as an organizational system. A weakness in one critical stage can become a bottleneck for the whole system. Each stage below is instantiated by one applied capability in this assessment.
02 · FIVE APPLIED CAPABILITIES

What this assessment measures

The instrument contains 15 assessment questions: three questions in each of five capabilities, one per stage of the model logic above.
03 · LIVE ASSESSMENT

Rate the organization

For every assessment question, give two scores: current state and target state. The gap between them, weighted by how important the target is, is what drives the priority ranking below.
What are the assessment questions? Every item marked ASSESSMENT QUESTION below is part of the formal evaluation instrument. Each one should receive both a Current state score and a Target state score.
